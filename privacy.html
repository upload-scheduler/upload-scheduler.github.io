Privacy Policy

Upload Scheduler · Last updated 15 November 2026

Upload Scheduler is a private tool used only by its owner to upload videos to the owner's own YouTube channel, currently Wild Biology. This policy explains what data it accesses and what it does with it.

Data the tool accesses

With the channel owner's permission, granted through Google sign-in, the tool uses two YouTube API permissions:

  • Upload videos (youtube.upload): to upload the channel owner's approved videos and their titles, descriptions, tags and publish times.
  • View your YouTube account (youtube.readonly): to read the channel's name and ID and the status of videos the tool uploaded.

It does not access comments, subscribers, viewers' data, other channels or any other Google service.

How the data is used

The data is used only to upload and schedule the channel owner's videos and to confirm that each upload succeeded. It is not used for advertising, analytics about other people, or training AI models, and it is never sold or shared with anyone.

Storage and security

The only stored credential is a Google authorization token, kept as a private secret in the channel owner's own cloud environment and used only by this tool. Video files and their text are kept in the channel owner's private project files. Upload results (video ID, schedule) are stored next to each video.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page. Once revoked, the stored token stops working and is deleted from the cloud environment. Videos already uploaded stay on the YouTube channel, where they can be managed or deleted in YouTube Studio.
